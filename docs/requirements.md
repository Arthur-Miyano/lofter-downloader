# LOFTER 下载器 — 功能需求文档

> 版本：1.0.2 | 日期：2026-05-25

## 一、项目目标

开发 LOFTER（网易乐乎）文章下载工具。用户通过浏览器 UI 操作，将 LOFTER 文章保存为本地文件，支持 Markdown（含图片）、TXT 纯文本、PDF 三种格式。

**核心约束：LOFTER 已于 2026 年实施全站登录墙。所有 `*.lofter.com` 页面在未登录时 302 重定向至 `/front/login`。因此所有下载操作均需先登录。**

## 二、功能列表

### F0：浏览器登录（前置功能）

用户通过 Playwright 启动的可见浏览器窗口手动登录 LOFTER（含拼图验证码），登录状态持久化到本地文件，后续下载自动复用。

**用户流程：**
1. 点击「启动浏览器登录」→ 弹出 Chrome 窗口，显示 LOFTER 登录页
2. 在浏览器中完成登录（手机扫码 / 账号密码 / 验证码）
3. 点击「检查登录」→ 系统验证登录成功，显示用户名
4. 登录状态自动保存，下次启动无需重新登录

**异常处理：**
- 浏览器启动失败 → 提示安装 Chromium
- 登录超时（5 分钟）→ 自动关闭 headed 浏览器，前端提示"登录超时，请重新启动"
- 会话过期（storageState 失效）→ 下载前检测登录状态，若已过期则前端提示重新登录
- 网络错误 → 提示"网络连接失败，请检查网络"
- 验证码未完成 → 提示"尚未检测到登录，请确认已在浏览器中完成登录"

### F1：下载单篇文章

根据文章链接，下载单篇文章。

- **前提：** 已完成 F0 登录
- **输入：** 文章 URL（如 `https://xxx.lofter.com/post/xxx_xxx`）
- **输出：** 文章保存至 `{download_dir}/单篇下载/` 目录
- **策略：** 加载文章页面 → 等待 SPA 渲染完成 → 提取内容 → 保存

### F2：下载作者全部文章

根据用户数字 ID，下载该作者全部公开文章。

- **前提：** 已完成 F0 登录
- **输入：** 用户数字 ID（如 `12345678`）
- **输出：** 文章保存至 `{download_dir}/{user_id}/` 目录
- **策略：**
  1. 解析用户 ID → 获取博客域名
  2. 主策略：DWR `ArchiveBean.getArchivePostByTime` API（时间戳游标分页，每批 50 篇）
  3. 备选策略：`?page=N` SSR 分页（仅旧模板有效）
  4. 逐篇下载，每篇间隔 `REQUEST_INTERVAL` 秒

### F3：下载喜欢文章

下载当前登录用户标记为"喜欢"的全部文章。

- **前提：** 已完成 F0 登录，且会话有效
- **输入：** 无（自动识别当前用户 ID）
- **输出：** 文章保存至 `{download_dir}/喜欢文章/` 目录
- **策略：** DWR `BlogBean.queryLikePosts` API（offset 分页，每批 100 篇）

### F4：多格式导出

文章可按以下三种格式之一导出：

| 格式 | 输出形式 | 图片处理 | 适用场景 |
|------|----------|----------|----------|
| Markdown (md) | 文件夹 `{标题}/index.md + images/` | 下载至 images/ 子目录 | 保留完整排版 |
| TXT (txt) | 单文件 `{标题}.txt` | 纯文本，无图片 | 阅读器使用 |
| PDF (pdf) | 单文件 `{标题}.pdf` | 纯文本，无图片 | 打印 / 分享 |

格式选择在 Web UI 中切换，偏好设置持久化至 localStorage。

### F5：自定义下载目录

用户可以指定下载文件的保存目录：

- **文本输入：** 直接输入目录路径，留空则使用默认目录 `~/lofter_downloads`
- **文件夹浏览：** 点击「浏览」按钮，通过系统文件夹选择器选取
- 路径偏好持久化至 localStorage

## 三、文章提取策略

每篇文章的提取按以下优先级尝试：

1. **JS 全局状态提取**（优先级最高） — `page.evaluate("window.__INITIAL_STATE__")` 直接读取 React 状态对象
2. **Next.js 数据提取** — `page.evaluate("document.getElementById('__NEXT_DATA__')?.textContent")` 读取 Next.js SSR 数据
3. **HTML 源码降级提取**（三合一） — 对 `page.content()` 进行：正则匹配嵌入式 JSON → CSS 选择器提取 DOM 内容

如果所有策略失败 → 该篇文章标记为失败，继续处理下一篇（不终止整个批量任务）。

## 四、输出格式

### 4.1 Markdown 文件结构

```
{download_dir}/
├── 单篇下载/
│   └── {文章标题}/
│       ├── index.md
│       └── images/
│           ├── 001.jpg
│           └── 002.png
├── {user_id}/
│   └── {文章标题}/
│       └── ...
└── 喜欢文章/
    └── {文章标题}/
        └── ...
```

### 4.2 TXT 文件结构

```
{download_dir}/
├── 单篇下载/
│   └── {文章标题}.txt
├── {user_id}/
│   └── {文章标题}.txt
└── 喜欢文章/
    └── {文章标题}.txt
```

TXT 内容为：标题 + 元数据（作者/日期/链接）+ 纯文本正文（从 HTML 提取）。

### 4.3 PDF 文件结构

同 TXT，扩展名为 `.pdf`。使用系统 CJK 字体（Windows 微软雅黑、macOS 苹方、Linux Noto Sans CJK），支持中文字符渲染。

### 4.4 Markdown 模板

```markdown
# {标题}

- **作者**: {作者}
- **发布日期**: {日期}
- **原文链接**: {URL}

---

{Markdown 正文}
```

## 五、Web UI 需求

- 单页面应用，CDN 加载 Tailwind CSS + Alpine.js，无需构建步骤
- 登录区域：显示登录状态、用户名（@username + 首字母头像）、登录/检查/清除按钮
- 下载设置：格式选择（Markdown / TXT / PDF 单选）、保存目录（文本输入 + 文件夹浏览按钮）
- 下载区域：单篇 URL 输入、作者 ID 输入（`type="text" inputmode="numeric"`，支持粘贴）、喜欢下载按钮
- 任务列表：实时显示所有任务的状态、进度条、错误信息（2 秒轮询）
- 已完成列表：独立区域显示历史任务（completed / failed / canceled），含时间戳

## 六、非功能需求

### 6.1 可靠性与容错

- 单篇文章下载失败不终止批量任务（记录日志，跳过，继续下一篇）
- 图片下载失败仅记录警告，不终止文章保存
- 图片下载需重试（最多 2 次），含指数退避（1s → 2s → 4s）
- 页面导航需重试（最多 2 次），含指数退避
- 批量下载中每篇文章之间需插入请求间隔（默认 2 秒），避免触发反爬
- 分页遍历中每页之间需插入请求间隔（默认 2 秒）
- 下载前检测登录会话有效性，过期时前端提示重新登录，禁止静默失败
- 含特定错误分类：网络错误、登录过期、解析失败、参数错误

### 6.2 并发与资源

- 同时最多允许 1 个下载任务运行（后续任务返回 409 错误）
- 登录期间同时存在两个 Chromium 进程：headless（持久化，下载用）+ headed（临时，登录用）。登录成功后立即关闭 headed
- 登录 headed 浏览器需 5 分钟超时自动关闭，避免资源泄漏
- 已完成/失败/取消的任务保留最多 100 条，超出时淘汰最旧记录
- 应用退出时清理所有浏览器进程（atexit 注册）

### 6.3 线程安全

- TaskManager 在 Flask 请求线程与浏览器事件循环线程间共享，所有读写操作需加锁保护
- 任务取消操作需同时：修改状态标志位 + 向事件循环发送 CancelledError

### 6.4 其他

- 单用户工具，无需数据库，所有任务状态存内存
- 登录会话存本地 JSON 文件（Playwright storageState 格式）
- 配置通过 `.env` 文件 + 环境变量管理，非法值时使用默认值而非崩溃
- 文章标题中的特殊字符需安全处理（`<>:"/\|?*` 替换为 `_`，去首尾空格和点，截断 200 字符）

## 七、边缘情况

| 场景 | 预期行为 |
|------|----------|
| 喜欢 API 无数据返回 | 返回错误"未找到任何喜欢文章，请确认已登录并有喜欢内容" |
| 下载中途登录会话失效 | 检测到重定向至登录页后，停止批量任务，更新状态为 FAILED，error 注明"登录会话已过期" |
| 退出登录时有下载任务运行中 | 取消所有运行中任务，关闭 headed 浏览器（如存在），清除会话文件 |
| 同时提交多个下载请求 | 若已有运行中任务，返回错误"已有下载任务在进行中，请等待完成" |
| 文章标题全部由特殊字符组成 | 降级为 `untitled_{timestamp}` |
| 配置文件中数值类型非法 | 使用默认值，记录警告日志，不崩溃 |
| 作者 ID 解析失败 | 返回错误"无法解析用户 ID"，不静默使用默认值 |

# LOFTER 文章下载器

> 一键下载网易 LOFTER（乐乎）平台的文章，保存为 Markdown 格式。

## 功能特性

- **单篇下载**：输入文章链接，一键下载单篇
- **作者全部文章**：输入作者数字 ID，下载所有公开发布文章
- **合集下载**：输入合集链接，下载合集内全部文章
- **收藏下载**：登录后下载自己的收藏文章
- **Markdown 输出**：文章保存为 .md 文件，图片保存在本地
- **美观 GUI**：基于浏览器，Tailwind CSS + Alpine.js，支持暗黑模式

## 快速开始

```bash
pip install lofter-downloader

# 启动 Web UI
python -m lofter_downloader
```

浏览器自动打开 `http://127.0.0.1:8080`。

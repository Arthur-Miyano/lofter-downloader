# 登录说明

## 为什么需要登录？

仅 **下载收藏文章**（F1）功能需要登录 LOFTER。其他功能（单篇、作者全部、合集）均无需登录。

## 获取 Cookie

1. 在浏览器中登录 [LOFTER](https://www.lofter.com)
2. 打开开发者工具（F12）
3. 切换到 **Network**（网络）标签
4. 刷新页面，找到任意请求
5. 在请求头中找到 `Cookie` 字段
6. 复制整个 Cookie 字符串

## 导入 Cookie

在 Web UI 中点击「管理登录」，将复制的 Cookie 粘贴到输入框中，点击「导入」即可。

## 安全性

- Cookie 会使用 AES 加密后存储在本地文件中
- 每次启动时自动加载保存的会话
- 可通过「清除」按钮手动删除
